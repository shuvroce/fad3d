        Usage Guide

        1
        Define Materials & Sections

        Use the Define dropdown on the floating bar to set up aluminum/steel materials and profile sections before creating categories.

        2
        Create Categories

        Click the + button on the category bar to add facade zones. Each category has Glass, Frame, and Anchorage input tabs.

        3
        Configure General Info

        Click General on the floating bar to fill in project details, revision number, and report sections.

        4
        Run Calculations

        Results update automatically as you enter data. Check the right panel for design summary, DC ratios, and deflection values.

        5
        Generate Report

        Click the Report button in the top bar to generate a PDF summary of your facade analysis.

        Tips

        • Hover over icons and buttons to see tooltips with descriptions.
        • Right-click a category tab to rename, duplicate, or delete it.
        • Use the Figures panel (top-right) to check which profile figure images are available.
        • Toggle dark mode using the moon/sun icon in the top-right corner.
        • Drag modal headers to reposition dialogs on screen.
        • Use the Settings modal to switch between design codes and unit systems.
